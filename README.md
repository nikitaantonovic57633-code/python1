# toolkit
Консольный набор утилит: калькулятор выражений и конвертер величин.

## Возможности
**Калькулятор**

* целые и вещественные числа ("1", "2.5", "0.001");
* операции "+", "-", "*", "/" с обычным приоритетом;
* унарные "+" и "-" перед числом ("-5", "+7", "--3");
* пробелы между токенами игнорируются ("1 + 2 * 3 эквивалентно "1+2*3");
* реализован без "eval", "exec", 'ast.literal_eval' и сторонних парсеров.

**Конвертер**
* длина: "mm", "cm", "m", "km";
* масса: "g", "kg";
* температура: "c", "f", "k";
* регистр единиц не учитывается ("m" эквивалентно "M");
* конвертация между разными группами запрещена;
* температура ниже абсолютного нуля невозможна.

## Требования
* Python 3.10 или новее.

## Установка
`pip install -e .`

`pip install pytest ruff`

## Использование
**Калькулятор**

`python -m toolkit calc 1*2-3`

`python -m toolkit calc -2*-3`

`python -m toolkit calc 10/4`

**Конвертер**

`python -m toolkit convert 100 --from cm --to m`

`python -m toolkit convert 0 --from c --to f`

`python -m toolkit convert 1 --from kg --to g`

**Справка**

`python -m toolkit --help`

После `pip install -e .` доступна короткая команда:

`toolkit calc "2+2"`

## Обработка ошибок
CLI сообщает об ошибке в stderr и завершается с кодом 2. Успешный запуск завершается с кодом 0.

**Калькулятор отклоняет:**
* пустое выражение;
* недопустимый символ ("2 + a");
* пропущенный операнд ("1 + ");
* два бинарных оператора подряд ("2 */ 3");
* деление на ноль ("1/0").

**Конвертер отклоняет:**
* неизвестную единицу;
* несовместимые единицы (m -> kg);
* неверное числовое значение;
* температуру ниже абсолютного нуля.
